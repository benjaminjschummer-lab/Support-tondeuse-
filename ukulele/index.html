Joue n'importe quelle chanson au ukulélé

Tape le titre : la grille d'accords s'ouvre, les accords s'enchaînent au tempo de la chanson. Touche un accord pour voir le doigté.

Les paroles ne s'affichent que dans la version en ligne : ouvrir Kanikapila en ligne ↗

Clé pour les accords : à ajouter

Les paroles viennent de LRCLIB (gratuit, sans clé). Pour placer les accords, colle une clé Gemini gratuite : va sur aistudio.google.com/apikey ↗, connecte-toi avec ton compte Google, touche « Create API key » et copie la clé (elle commence par AIza). Sans carte bancaire. Sur l'offre gratuite, Google peut utiliser les demandes (titre et paroles) pour améliorer ses modèles. Une clé Anthropic payante (sk-ant-…) marche aussi. La clé reste dans ce navigateur.
